# تتبع مصاريف الراتب

تطبيق ويب للجوال لمتابعة ميزانية راتب شهري قدره 760 ر.ع. مبني بـ React وTailwind CSS وLucide.

- `index.html`: التطبيق كاملاً في ملف واحد. افتحه مباشرة في المتصفح (Safari على الآيفون يدعم "إضافة إلى الشاشة الرئيسية")، ومنه تعمل الطباعة وحفظ PDF.
- `src/`: الشيفرة المصدرية (`App.jsx` للواجهة و`data.js` للبنود والبيانات التجريبية و`index.css` للألوان والطباعة).
- البناء: `npm install && npm run build`.

البيانات تُحفظ في `localStorage` على الجهاز نفسه، وزر "إعادة ضبط" في صفحة الطباعة يعيد الإعدادات الافتراضية.
