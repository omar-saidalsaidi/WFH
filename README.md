# تتبع مصاريف الراتب

تطبيق ويب للجوال (عربي، من اليمين لليسار) لإدارة الراتب والمصروفات شهراً بشهر. مبني بـ React وTailwind CSS وLucide، ويعمل كاملاً من ملف واحد دون إنترنت.

- `index.html`: التطبيق كاملاً في ملف واحد. افتحه في Safari وأضفه إلى الشاشة الرئيسية.
- البيانات محفوظة محلياً على الجهاز فقط (`localStorage`).

## الميزات

- **الأشهر:** كل شهر مستقل براتبه وبنوده وعملياته. يمكن عند بدء شهر جديد ترحيل الفائض أو العجز كرصيد منفصل عن الراتب. يُثبَّت الرصيد المرحّل عند بدء الشهر ولا يتغير إلا يدوياً.
- **المخطط والفعلي:** لكل بند المخطط (المخصص)، والمدفوع (المسجل فعلياً)، والمتبقي، ونسبة التنفيذ.
- **الرصيد المتوقع نهاية الشهر:** الرصيد الحالي ناقص المخصصات والالتزامات غير المدفوعة. وإن كانت وتيرة الصرف اليومي على بند تشغيلي أعلى من مخصصه، يُحسب على الوتيرة الفعلية.
- **التنبيهات:** عند بلوغ 80٪ أو تجاوز 100٪ من ميزانية أي بند، وعند اقتراب يوم الاستحقاق أو التأخر عنه، وعند اقتراب أقساط الديون.
- **التحليل السنوي:** مقارنة آخر 12 شهراً للراتب والمدفوع والادخار، مع اتجاه الإنفاق وأكثر البنود استهلاكاً.
- **الديون:** الرصيد المتبقي (يُخصم منه ما يُسجَّل على البند المرتبط)، والأقساط القادمة، وتاريخ الانتهاء المتوقع.
- **أهداف الادخار:** نسبة الإنجاز والمبلغ المطلوب شهرياً حتى الموعد.
- **محاكاة السيناريوهات:** أثر تغيير الراتب أو مخصص بند أو إضافة قسط، دون تعديل البيانات.
- **النسخ الاحتياطي:** تصدير واستيراد JSON لكل الأشهر مع بصمة للتحقق. يُفحص الملف قبل الاستبدال، وتُحفظ نسخة تلقائية قبل أي استيراد أو مسح أو حذف شهر.
- **التقارير:** PDF وExcel، شهري وسنوي.
- **إدارة الفئات:** إضافة فئة وتسميتها وترتيبها وتحديد نوعها (التزامات ثابتة أو مصاريف مرنة) وحذفها. الفئة التي فيها بنود لا تُحذف إلا بعد نقل بنودها إلى فئة أخرى، فلا تضيع أي عملية. يُطبَّق كل تعديل على الشهر الحالي فقط، أو عليه وعلى الأشهر المحفوظة بعده؛ والأشهر السابقة لا تتغير أبداً.
- **ألوان الفئات:** ثمانية ألوان باستيل لبطاقة كل فئة، مع درجات مكافئة في الوضع الداكن.
- **تحليل سلوك الإنفاق (الأدوات):** محرك قواعد حسابية واضحة يعمل على الجهاز فقط (وليس ذكاءً اصطناعياً)، يقارن المخطط بالفعلي، ويرصد تكرار التجاوز والزيادات غير المعتادة والملاحظات المتكررة، ويقترح توفيراً عملياً في المصاريف المرنة فقط. المحرك منفصل في `src/insights.js` ليمكن إضافة محرك آخر لاحقاً بموافقة صريحة من المستخدم.

## البنية

| الملف | المحتوى |
| --- | --- |
| `src/finance.js` | كل الحسابات المالية (بلا واجهة) |
| `src/sections.js` | عمليات الفئات ونطاق تطبيقها على الأشهر |
| `src/insights.js` | محرك تحليل سلوك الإنفاق |
| `src/data.js` | البيانات الافتراضية والتحميل والترحيل والنسخ التلقائية |
| `src/backup.js` | النسخ الاحتياطي والتحقق من سلامة البيانات |
| `src/exporters.js` | ملفات Excel والمشاركة والتنزيل |
| `src/App.jsx`، `src/features.jsx`، `src/sectionsView.jsx`، `src/insightsView.jsx`، `src/reports.jsx`، `src/ui.jsx` | الواجهة |

## التشغيل والاختبار

```bash
npm install
npm run build      # يبني index.html
npm test           # اختبارات الحسابات والنسخ الاحتياطي والترحيل
npm run test:e2e   # اختبارات وظيفية في متصفح بحجم آيفون (يتطلب Playwright وأدوات poppler)
```
